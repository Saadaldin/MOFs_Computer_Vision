# Recognition of Pore Shapes in MOFs Using Computer Vision

A computer vision-based workflow is developed to recognize unique pore shapes in MOFs.

(1) Voxelized MOF images are first generated by depicting the pore and framework regions within the crystal structures.

<img width="652" height="235" alt="image" src="https://github.com/user-attachments/assets/c951870b-82d5-41ca-933d-0194b7218ea6" />

(2) The enclosed pore shapes are then detected using contour detection and polygon approximation methods. 

<img width="650" height="152" alt="image" src="https://github.com/user-attachments/assets/002bc44b-6740-4967-8689-b6626447d539" />



(3) A convolutional neural networks-based autoencoder (CNN-E) is also employed to learn a compressed latent representation of the images.
