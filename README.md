# Recognition of Pore Shape in MOFs Using Computer Vision

A computer vision-based workflow is developed to recognize unique pore shape in MOFs.

(1) Voxelized MOF images are first generated by depicting the pore and framework regions within the crystal structures.

(2) The enclosed pore shapes are then detected using contour detection and polygon approximation methods.
